# Disk Scheduling

Exploring FCFS, SSTF, SCAN, C-SCAN and LOOK strategies for ordering disk requests.

## Programs

- `C_SCAN_Disk_Scheduling.c`
- `FCFS_Disk_Scheduling.c`
- `LOOK_Disk_Scheduling.c`
- `SCAN_Disk_Scheduling.c`
- `SSTF_Disk_Scheduling.c`

## Compile and Run

For a standard C program:

```bash
gcc program.c -o program
./program
```

For programs that use POSIX threads:

```bash
gcc program.c -o program -pthread
./program
```

Replace `program.c` with the source filename you want to run. Some programs require Linux or WSL. Compile each source file separately.
